# Painted art drop-zone

Drop images here with the exact names below and the game picks them up at boot.
Missing files are ignored — the engraved vector marks stay in place.

```
units/senapati.png       units/maharathi.png    units/ashvarohi.png
units/dhanurdhar.png     units/divyadrishti.png units/yantrik.png
units/rath.png           units/chara.png        units/shataghni.png
units/durg.png
factions/suryavansh.png  factions/chandravansh.png
boards/wheel.jpg         boards/small.jpg       boards/large.jpg
ui/combat.jpg            ui/victory.jpg         ui/defeat.jpg      ui/hero.jpg
app/icon-1024.png
```

- **Unit pieces and crests:** 512×512 PNG, subject on pure flat black (#000000) — the black
  is keyed out to transparency.
- **Board surfaces:** 2048×2048 JPG, dark and low contrast (they render at 42% under the cells).
- **Scene art:** 1536×768 JPG (hero 1920×1080).

Full prompts for each slot: `docs/art-brief.md`.
