# VYUHA — 3D pack

VYUHA plays in 2D (an SVG board), so 3D is never on the critical path. It earns its place in
four ways, in this order:

1. **A physical prototype** of the board game — 3D-printed pieces to playtest at a real table
   (and for the board-game venture).
2. **Renders for the store and the trailer** — brass pieces on a stone chakra, lit like a temple.
3. **Consistent piece art** — render each 3D piece from the same camera and light to get a set
   of 2D piece images that match perfectly.
4. **A future 3D table mode** (three.js), only if players ask for it.

## Already in the repo — no credits needed

`tools/make-pieces-3d.py` builds all ten pieces in code. Run it any time:

```bash
pip install trimesh numpy shapely matplotlib mapbox_earcut manifold3d
python3 tools/make-pieces-3d.py
```

| Output | Use |
|---|---|
| `assets/3d/stl/<piece>.stl` | 3D printing, in millimetres, on a 28 mm base (standard miniature size). |
| `assets/3d/glb/<piece>_surya.glb` | Brass finish, for Blender, renders, web 3D (metres). |
| `assets/3d/glb/<piece>_chandra.glb` | Silver-indigo finish. |
| `assets/3d/preview.png` | Contact sheet of the set. |

Ten figurines plus one table tile. Each figurine has the same column and its own top: a crown of rays (Senapati), a twelve-spoke wheel
(Maharathi), a horse head (Ashvarohi), a drawn bow (Dhanurdhar), an eye in a ring
(Divyadrishti), a gear (Yantrik), a six-spoke wheel (Rath), a katar (Chara), a spiked iron ball
(Shataghni), a fort tower with a gate (Durg). 1.8k–5.5k triangles each.

Most pieces export as one watertight solid; a few (the wheels, the katar) are overlapping
shells, which every slicer (Cura, PrusaSlicer, Bambu Studio) merges automatically.

**To print a prototype:** 0.2 mm layers, 15% infill, no supports for most pieces (the bow and the
wheels may want tree supports).

**Figurines show their rank, so they are for display, renders and the box cover.** For a
*playable* table version, ranks must stay hidden from the opponent — that is what
`assets/3d/stl/tile.stl` is for: an upright stone on the same 28 mm base, with a recess on one
face for a sticker of the piece art. Each player sees their own faces; the opponent sees only
stone. Print 12 tiles in gold PLA and 12 in silver or indigo, and print the stickers from the
piece art in `assets/art/units/`.

## Making better-looking pieces

### Route A — refine the starter set in Blender (free)

1. File → Import → glTF 2.0 → pick a `_surya.glb`.
2. Add a Bevel modifier (0.3 mm) and Shade Auto Smooth for a cast-metal look.
3. Sculpt or model the top; keep the shared column and base so the set stays consistent.
4. Export back to `incoming/3d/<piece>.glb` (and `.stl` for printing).

You can ask ChatGPT for help with exact Blender steps or a Blender Python script — give it the
file name and say what to change (for example, *"make the Senapati's crown look like a
temple shikhara"*).

### Route B — image to 3D (Meshy, Tripo, Rodin, etc.)

This spends credits, so make a perfect reference image first.

**Step 1 — reference image** (ChatGPT or Gemini, square 1024², plain light-grey background):

> Product photo of a single board-game miniature on a plain light grey background, three-quarter
> front view, soft studio light: a carved brass figurine on a 28 mm round stepped base with a
> slim column, topped by **[TOP]**. Polished antique brass with darker recesses, crisp details,
> one object only, no text, no shadow clutter.

| Piece | [TOP] |
|---|---|
| Senapati | a crown of twelve sun rays around a small sphere, like a temple finial |
| Maharathi | an upright chariot wheel with twelve spokes and a spear through the hub |
| Ashvarohi | a horse head in profile wearing a small chamfron, mane swept back |
| Dhanurdhar | a drawn recurve bow with a nocked arrow, standing upright |
| Divyadrishti | an open almond eye inside an orbiting ring |
| Yantrik | an upright cog wheel crossed with a spanner |
| Rath | an upright light chariot wheel with six spokes |
| Chara | an upright katar punch-dagger, blade pointing up |
| Shataghni | a spiked iron ball on a low tripod (iron, not brass) |
| Durg | a square fort tower with crenellations and an arched gate |

**Step 2 — image to 3D** with that picture. Settings: target ≈ 20k triangles, PBR textures,
GLB output. Ask for **"single object, closed mesh, flat base"**.

**Step 3 — save** as `incoming/3d/<piece>.glb` (and `.stl` if the tool offers it).

**Check before sending:** the piece stands on its base; height 40–60 mm when scaled to a 28 mm
base; the top reads from across a table; no floating bits.
